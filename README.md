# Rebound-Game

A 2D pixel-art platformer made by me and my team using Godot 4.7. Created for the **Haven Focșani Hackathon**, in Vrancea, Romania.

## Overview

Reboundis a small platformer game where you collect coins, avoid annoying slime enemies and try to reach the end. We wanted to make a platformer game using free assets because of lack of time and experience

The game is made in Godot 4.7 and is designed to be playable directly in your browser. Hope you enjoy it!

## Features

- 2D platformer gameplay
- Coin collecting because who doesn't like coins
- Slime enemies that get in your way
- Pixel-art graphics made in Linux Mint Paint lol
- Browser-based gameplay

## Game Engine

The game is made using **Godot Engine 4.7**.

- Engine: Godot 4.7
- Language: GDScript
- Platform: Web (HTML5)
- Art style: Pixel Art

## How to Play

1. Move around the level using WASD and arrow keys.
2. Jump over obstacles and avoid slimes.
3. Collect as many coins as possible.
4. Reach the end of the level!
